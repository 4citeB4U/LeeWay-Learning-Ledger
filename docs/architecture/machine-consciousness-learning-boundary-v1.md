# Machine Consciousness ↔ Learning Ledger boundary

Canonical map: [Machine Consciousness cross-repository integration v1](https://github.com/4citeB4U/Machine-Consciousness/blob/main/docs/architecture/leeway-cross-repository-integration-v1.md).

Learning Ledger consumes Receipt Authority evidence and Continuum-confirmed state. It may admit verified outcomes, failures, capability combinations, measured costs, transfer relationships, capability debt, and recovery outcomes. It may improve routing, diagnosis, recovery, composition, and explanation.

It must not create authority, permissions, identity, Formula results, Veritas decisions, or execution evidence. Local G3 metadata may be banked in the Machine Consciousness replay manifest, but it is not external Learning Ledger admission until the real replay, verification, receipt, and Continuum readback are complete.
